SI-101 · ASK SYNINTEL

A business question in, a cited answer out.

We'd open the walkthrough with this module. A user asks a plain-language question. A planner agent breaks it into sub-tasks, specialist agents answer them from the graph and the source systems, and a policy agent checks what that user is allowed to see before the answer is written.

  • Six-agent trace, visible step by step: planner, retriever, graph reasoner, analyst, guardrail and synthesiser
  • Every claim cited back to a contract, a purchase order or a ticket
  • Permission-aware: the same question gives a different answer to a CXO and to Legal
  • Actions need approval: the agent drafts the ServiceNow request, and a person approves it

SI-102 · AGENT ORCHESTRATOR

Agents released like software, not like demos.

Every agent is defined in a versioned spec: its tools, its model route, how long its memory lasts and which guardrails apply. It cannot reach production until it passes an evaluation suite and a canary rollout.

  • Model routing: a large model for planning, a small fast model for retrieval, and a self-hosted fallback for tenants with data-residency requirements
  • Release gate on accuracy, citation faithfulness, tool-call success, cost and latency
  • Human in the loop: any tool that writes to a system of record requires approval

SI-103 · KNOWLEDGE GRAPH

Define each entity once, then link it across every system.

The ontology defines entities like Supplier, Contract and Plant once. Entity resolution then links "Acme Ltd" in SAP to "ACME Limited" in a scanned contract. That is how the agent in SI-101 traced a single-source component through to at-risk revenue in one step.

  • Interactive graph explorer: click a node to see its properties, its source system and its neighbours
  • Ontology you can version, with industry packs extending the core classes
  • Hybrid retrieval: graph traversal and vector search in the same query

SI-104 · DATA & ANALYTICS

Pipelines with owners, SLAs and tests.

Data arrives through change-data-capture from ERP, streaming from CRM and plant systems, and document parsing with OCR. It all lands in an open-format lakehouse. The gold layer then serves three consumers: the dashboards, the feature store and the knowledge graph.

  • Lineage from source to graph, from bronze through silver to gold
  • Data-quality monitors that flag anomalies before an agent can use bad data
  • One semantic metrics layer, so "revenue" means the same thing in BI, SQL and the Analyst agent

SI-105 · INTEGRATIONS & APIs

Works with the systems customers already run.

Connectors read from SAP, Salesforce, ServiceNow, Microsoft 365, Snowflake, Workday, Kafka and older ERPs. They write back only through approved actions. Everything in the console is also available through a versioned public API.

  • Live connector health with latency and last sync, so a degraded connector is visible before it causes a problem
  • On-behalf-of API calls that go through the same policy engine as the console, with no admin bypass
  • Cost ceilings per request (max_cost_inr) so API callers can't overspend on inference

SI-106 · SECURITY & GOVERNANCE

The model only sees what the user is allowed to see.

Enterprise buyers ask about this first, so we treat it as a core feature. Policies are applied when data is retrieved, before anything reaches the LLM. You can switch roles in the console and watch the same contract record change.

  • Field-level masking and redaction for each role: CXO, Procurement, Analyst and Legal
  • Prompt-injection detection on retrieved documents, with blocks recorded in the audit log
  • Tamper-evident audit trail linking every answer to the exact records it used
  • SSO, SCIM, data residency, and customer-managed keys on the roadmap

SI-107 · CLOUD & DISTRIBUTED

Deployable in-region, with a fully on-premise option.

For expansion into new markets, where the platform can be deployed matters as much as what it does. The architecture uses regional cells for data residency, a warm-standby DR region, and a fully air-gapped deployment for regulated customers that runs on open-source models.

  • Autoscaled GPU inference pool with a queue in front of it, sized to traffic
  • Event-sourced core on Kafka, with idempotent consumers and circuit breakers on every connector
  • Cost per tenant visible, so pricing decisions are based on real unit costs

SI-109 · EDGE AI, IoT & INTELLIGENT CCTV

The ninth capability: security for the physical site.

Enterprise intelligence also depends on what happens at the gate, on the shop floor and along the fence. We design and build TinyML and IoT monitoring systems and AI-powered CCTV, and connect them to SynIntel. A camera or sensor event then becomes a record the agents can reason over.

SI-109 · INTELLIGENT CCTV & SECURITY

Cameras that report events, not hours of footage.

Vision models run on a Jetson or Hailo edge box beside the cameras. Each site sends SynIntel events such as a plate read, a missing hi-vis vest or a tripwire crossing. A Security Analyst agent combines related signals (thermal camera, PIR sensor, fence vibration) into one incident with a recommended next step.

  • Six example detections: ANPR at the gate, PPE in the loading bay, aisle occupancy, thermal perimeter intrusion, server-room tamper, smoke and haze on the line
  • Multi-sensor fusion, which suppresses 92% of false alarms before anyone is paged
  • Privacy on the device: faces are blurred before storage, and unblurring requires the Investigation role and is recorded in the audit log
  • Works with existing cameras over ONVIF / RTSP, with no camera replacement

SI-109b · TinyML & IoT FLEET

Machine learning in 38 kilobytes, on battery power.

Some sensors can't stream data: they run on batteries, sit on a LoRaWAN link, or are installed where the network is unreliable. For these we run the model on the microcontroller itself. A vibration autoencoder on an STM32 detects bearing wear about 11 days before failure and drafts the SAP PM work order.

  • Model registry of int8 models from 38 KB (vibration) to 6.2 MB (PPE), each with its size, accuracy and latency on the target hardware
  • Live site map of cameras, PIR, door, thermal, acoustic and air-quality sensors
  • Signed OTA rollouts in stages, with A/B partitions and automatic rollback
  • 96% less uplink data, because devices send events rather than raw streams

SI-6XX · WHAT'S SEALED

Proposed next-phase modules.

Each of these nine next-phase modules plugs into a part of the architecture that already exists in the prototype. They stay switched off until SynIntel decides which roadmap themes to prioritise.

Agent marketplace

Customers and partners publish agents built on a shared spec. Each agent passes an evaluation gate before it can be listed, and customers can install one per tenant.

Ties to → Agent Orchestrator, Eval harness

Auto-ontology from documents

Proposes new ontology classes and relationships from a customer's own documents, with a person reviewing them before they're merged. This shortens onboarding from weeks to days.

Ties to → Knowledge Graph, Doc parsing

Connector SDK

Lets implementation partners build connectors for regional ERPs themselves, with certification tests, so SynIntel can enter new markets without waiting on core engineering.

Ties to → Integrations & APIs

Customer-managed keys

Encryption keys held by the customer, per tenant, with revocation. Banks and hospitals typically require this before they sign.

Ties to → Security & Governance, Cloud

BFSI industry pack

KYC / AML entity resolution, analysis of how regulatory changes affect a bank, and a credit-memo drafting agent, with a compliance profile mapped to local regulators.

Ties to → Industry Packs, Knowledge Graph

Healthcare industry pack

HL7 / FHIR connectors, clinical document summarisation and claims anomaly detection, with controls for protected health information (PHI) in the policy engine.

Ties to → Industry Packs, Governance

Federated learning at the edge

TinyML models learn each machine's normal behaviour on-site and share only weight updates, never sensor data, so the whole fleet improves without data leaving any site.

Ties to → TinyML & IoT Fleet, Governance

Natural-language video search

Queries like "Show every forklift near a person without a vest last week" answered from event metadata and on-site embeddings, without uploading footage.

Ties to → Intelligent CCTV, Ask SynIntel

Access control & visitor integration

Badge readers, turnstiles and the visitor system connected to the graph, so a tailgating event is checked against the roster and the visitor list automatically.

Ties to → Intelligent CCTV, Integrations
